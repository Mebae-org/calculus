# 課題 05 - 定積分の応用

- 対象範囲: [`../docs/index.md`](../docs/index.md) 第5章全体
- 配点: 30点（各問10点）
- 提出方法: [課題05提出フォーム](https://github.com/Mebae-org/calculus/issues/new?template=assignment-ch05.yml)
- 採点: GitHub Actionsによる自動採点（絶対誤差 $10^{-6}$ 以内）

解答欄には整数または小数だけを入力してください。円周率や対数を含む答えは小数点以下6桁以上で入力してください。

## 問1（10点）

曲線 $y=x^2-2x$ と直線 $y=x$ が囲む領域の面積を求めなさい。

## 問2（10点）

曲線 $y=x^2/4-(\log x)/2$ の $1\le x\le2$ における弧長を求めなさい。

## 問3（10点）

$0\le x\le2$, $x^2\le y\le2x$ で定まる領域を $x$ 軸のまわりに回転した立体の体積を求めなさい。

# 第5章 定積分の応用

## 概要

定積分を、平面図形の面積、曲線の長さ、立体の体積の計算に応用します。面積では定積分の符号と幾何学的面積を区別し、交点や符号変化点で積分区間を分割します。体積では断面積法を基本に、円板法・ワッシャー法・円筒殻法を図形と回転軸に応じて使い分けます。

## 前提知識

- 定積分と微積分学の基本定理
- 置換積分と基本的な積分計算
- 関数のグラフ、交点、増減

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 符号付き面積と幾何学的面積を区別できる
- [ ] 交点・零点を求め、面積の積分区間を正しく分割できる
- [ ] グラフ $y=f(x)$ の曲線の長さを求められる
- [ ] 断面積 $A(x)$ または $A(y)$ から体積積分を立式できる
- [ ] 円板法・ワッシャー法・円筒殻法を適切に選択できる
- [ ] 積分結果の符号・次元・概算を用いて答案を検算できる

## モデルコアカリキュラムとの対応

| 到達目標 |
|----------|
| 定積分を利用して面積を求めることができる |
| 定積分を利用して曲線の長さを求めることができる |
| 定積分を利用して体積を求めることができる |

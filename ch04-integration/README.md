# 第4章 積分

## 概要

不定積分を微分の逆演算として捉え、微積分学の基本定理によって定積分と導関数を結び付けます。置換積分と部分積分を使い分け、三角関数、指数・対数関数、有理関数、根号を含む関数の代表的な積分を計算します。

## 前提知識

- 初等関数の微分公式と合成関数・積の微分法を使えること
- 連続性と区間、総和の基本的な意味を理解していること
- 多項式の因数分解と平方完成ができること

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 原始関数と積分定数の意味を説明できる
- [ ] 微積分学の基本定理を用いて定積分と積分関数を計算できる
- [ ] 置換積分と部分積分を適切に選択できる
- [ ] 三角・指数・対数関数の基本的な積分を計算できる
- [ ] 部分分数分解や平方完成を用いて有理関数を積分できる
- [ ] 根号の形に応じて代数的置換または三角置換を選べる

## モデルコアカリキュラムとの対応

| 到達目標 |
|----------|
| 導関数の公式を利用して不定積分を求めることができる |
| 微積分学の基本定理を理解し、不定積分から定積分を求めることができる |
| 置換積分及び部分積分を利用して不定積分や定積分を求めることができる |
| 初等関数を含む関数の不定積分・定積分を求めることができる |

# 第7章 多変数微積分

## 概要

二変数関数を中心に、偏微分の連鎖律、2階までの偏導関数、極値判定、二重積分を学びます。直交座標と極座標を使い分け、領域上の体積を二重積分で表して計算できることを目指します。

## 前提知識

- 一変数関数の微分、連鎖律、極値
- 一変数関数の定積分と置換積分
- 三角関数の基本公式

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 合成関数の偏導関数を連鎖律で計算できる
- [ ] 2階までのすべての偏導関数を計算し、混合偏導関数が等しくなる条件を説明できる
- [ ] ヘッセ行列を用いて二変数関数の内部臨界点を分類できる
- [ ] 閉領域で境界と端点を含めて最大値・最小値を調べられる
- [ ] 一般領域上の二重積分を累次積分として計算できる
- [ ] 極座標変換のヤコビアンを用いて二重積分を変換できる
- [ ] 曲面間の体積を二重積分で表現し、計算できる

## モデルコアカリキュラム

| 到達目標 |
|----------|
| 合成関数の偏微分法などから第2次までの偏導関数を求めることができる |
| 二変数関数の極値を求めることができる |
| 累次積分と極座標変換により二重積分を計算できる |
| 二重積分を利用して体積を求めることができる |

## 学習の進め方

1. 偏微分では「どの変数を固定するか」を毎回確認します。
2. 極値問題では内部だけで終えず、領域の境界と端点を確認します。
3. 二重積分では積分領域を図示してから積分順序や座標系を選びます。
4. 本文の例題を解いた後、練習問題で計算と条件確認を反復します。

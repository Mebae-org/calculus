# 課題 07 - 多変数微積分

- 対象範囲: [`../docs/index.md`](../docs/index.md) 7.1--7.6
- 配点: 30点（各問10点）
- 提出方法: [課題07提出フォーム](https://github.com/Mebae-org/calculus/issues/new?template=assignment-ch07.yml)
- 採点: GitHub Actionsによる自動採点（絶対誤差 $10^{-6}$ 以内）

解答欄には整数または小数だけを入力してください。体積は小数点以下6桁以上で入力してください。

## 問1（10点）

$z=u^2v+\log v$, $u=x^2+y$, $v=e^{x-y}$ とする。点 $(x,y)=(0,0)$ における $\partial z/\partial x$ を求めなさい。

## 問2（10点）

閉円板 $x^2+y^2\le4$ 上における $f(x,y)=x^2+2y^2$ の絶対最大値を求めなさい。

## 問3（10点）

放物面 $z=9-x^2-y^2$ と円錐 $z=\sqrt{x^2+y^2}$ に挟まれる立体の体積を求め、小数で答えなさい。

# 第3章 微分の応用

## 概要

導関数の符号から関数の増減と極値を調べ、閉区間での最大値・最小値を求めます。さらに、接線、2階導関数による凹凸と変曲点、媒介変数表示された曲線の微分を扱います。

## 前提知識

- 関数の定義域、連続性、極限を理解していること
- 積・商・合成関数の微分法を使えること
- 初等関数の1階導関数と2階導関数を計算できること

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 定義域、臨界点、端点を確認して増減表を作れる
- [ ] 極大・極小と大域的な最大・最小を区別して求められる
- [ ] 微分可能性を確認し、曲線の接線の方程式を立てられる
- [ ] 2階導関数から凹凸を判定し、変曲点を特定できる
- [ ] 媒介変数表示から1階・2階導関数と接線を求められる

## モデルコアカリキュラムとの対応

| 到達目標 |
|----------|
| 導関数からグラフの概形を把握し、極値や最大値・最小値を求めることができる |
| 接線の方程式を求めることができる |
| 第2次導関数からグラフの凹凸を判定できる |
| 媒介変数表示された関数の導関数を計算できる |

# 第2章 微分法の公式

## 概要

積・商・合成関数の微分法を学び、三角関数、指数関数、対数関数、逆三角関数を正しい定義域と条件のもとで微分します。複数の公式を組み合わせ、複雑な関数を構造ごとに分解して微分する力を身に付けます。

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 積の微分法と商の微分法を使い分けられる
- [ ] 合成関数の内側と外側を見分け、連鎖律を適用できる
- [ ] 三角関数、指数関数、対数関数を微分できる
- [ ] 逆三角関数の導関数を定義域とともに使える
- [ ] 複数の微分公式を組み合わせ、結果を検算できる

## モデルコアカリキュラム

| 到達目標 |
|----------|
| 積及び商の導関数を求めることができる |
| 合成関数の微分法を利用した計算ができる |
| 三角・指数・対数・逆三角関数を含む関数の導関数を求めることができる |

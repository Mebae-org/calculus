# 第6章 Taylor級数と複素数

## 概要

滑らかな一変数関数を多項式で局所近似する Taylor 展開と、展開が元の関数に一致するための剰余項・収束条件を学びます。後半では指数関数、正弦、余弦の Maclaurin 級数から Euler の公式を導き、複素数の極形式、べき乗、方程式の根、振動の表現に応用します。

## 前提知識

- 一変数関数の高階導関数
- 数列・級数の収束と絶対収束
- 実数上の指数関数、三角関数
- 複素数の四則演算

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] Taylor 多項式を中心 $a$ のまわりで構成できる
- [ ] Lagrange 剰余項を用いて近似誤差を評価できる
- [ ] Taylor 級数が元の関数に一致するための条件を説明できる
- [ ] 代表的な Maclaurin 級数とその収束範囲を使える
- [ ] べき級数の収束半径と端点での収束を判定できる
- [ ] Euler の公式を級数から導き、複素数の計算に応用できる
- [ ] 複素指数関数を三角関数、方程式、振動の表現に利用できる

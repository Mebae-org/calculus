# 第1章 極限と導関数

## 概要

関数の極限を「値を代入すること」と区別して理解し、微分係数を差商の極限として定義します。接線の傾きと瞬間変化率という二つの意味を結び付け、べき関数を定義から微分できるようにします。

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 片側極限を用いて関数の極限が存在するか判定できる
- [ ] 極限の四則演算を、分母などの条件を確認して利用できる
- [ ] 微分係数と導関数を差商の極限で説明できる
- [ ] 微分係数を接線の傾きおよび瞬間変化率として解釈できる
- [ ] べき関数と多項式を微分し、接線の方程式を求められる

## モデルコアカリキュラム

|----------|

# 第8章 微分方程式

## 概要

未知関数とその導関数の関係を記述する常微分方程式を扱います。変数分離形、1階線形方程式、定数係数2階同次線形方程式を解き、初期条件から一意な解を決定します。

## 前提知識

- 一変数関数の微分と積分
- 指数関数、対数関数、三角関数
- 複素数と二次方程式

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 変数分離形を識別し、定数解を失わずに一般解を求められる
- [ ] 1階線形方程式を標準形に直し、積分因子で解ける
- [ ] 定数係数2階同次線形方程式の特性方程式を立てられる
- [ ] 異なる実根、重根、複素共役根ごとの一般解を書ける
- [ ] 2つの初期条件から積分定数を決定できる
- [ ] 解を元の微分方程式と初期条件に代入して検算できる

## モデルコアカリキュラム

| 到達目標 |
|----------|
| 変数分離形の微分方程式を解くことができる |
| 1階線形微分方程式を解くことができる |
| 定数係数2階同次線形微分方程式を解くことができる |

## 学習の進め方

1. 方程式の型を判定してから解法を選びます。
2. 一般解を求めた後に初期条件を適用します。
3. 変形中に割った式が0となる解を別に確認します。
4. 最後に微分して元の方程式へ代入します。
